# MozgAI Landing Page

## Edit button destinations
Open `index.html` and change these two lines:

```html
const EVENTORG_URL = 'https://your-eventorg-link-here';
const HOUSEHOLD_FINANCE_URL = 'https://your-household-finance-link-here';
```

Replace them with your real links.

## Files
- `index.html` - landing page
- `logo.png` - logo image

## Upload to GitHub
1. Create a new repository on GitHub.
2. Upload `index.html`, `logo.png`, and `README.md`.
3. Commit the files.
4. If using GitHub Pages, set the site source to the main branch root.
